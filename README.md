# GRQ_Route_Development_Dashboard
A route development branded to Groningen Airport Eelde branding. 

This dashboard is built to visualize data which is retrieved from MK-Metric or similar tools. The dashboard is able to handle .xlsx (Excel) and .csv (Excel) files, with multiple tabs. This dashboard is especially built around the tabs in the provided Excel file and extra added tabs will not work without a code update. Code update requests can be done via: jraviationsolutions@gmail.com. 

How to use it:
1) Fill in the Excel (.xlsx) template.
2) Open the dashboard here: https://grqroutedevelopmentdashboard-dfkhychehrgwjcvrvdn8de.streamlit.app/#surface-leakage-analysis-unserved-catchment-demand
3) Upload the Excel (.xslx) file on the left handside.
4) The data will imported and read in the dashboard.
